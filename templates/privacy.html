1. 我们是谁

「抽象派档案馆」（下称"本站"）是一个 Discord 社区数据分析看板，由社区管理员运营，通过 Discord 机器人收集服务器内公开频道与论坛（Forum）的讨论数据，并以统计图表的形式展示。本政策说明本站收集、使用、存储和保护数据的方式。

2. 我们收集的数据

2.1 通过 Discord OAuth 登录收集

  • 你的 Discord 用户 ID、用户名、头像——用于创建和识别你的账户；
  • 你所在服务器的列表及你在其中的权限（所有者 / 管理员）——用于判断你可以查看哪些服务器的数据。该列表仅在你登录时获取一次。

2.2 通过数据下载机器人收集（来自已授权分析的服务器）

数据说明
消息内容与时间戳服务器内公开频道与 Forum 帖子中的消息文本及发送时间
消息 ID 与回复关系用于还原讨论串结构
表情回应（Reactions）谁对哪条消息用了什么表情，用于热度统计
@提及谁提到了谁，用于互动关系统计
附件元数据附件的文件名、URL、大小（不下载附件内容本身）
成员名单服务器成员的用户 ID、昵称、头像（成员加入/更新时同步）

2.3 通过机器人互动功能收集

  • 收藏：你收藏了哪个帖子（用户 ID、服务器 ID、帖子 ID、时间）；
  • 拉黑：你拉黑了谁、拉黑时间，以及机器人替你拦截消息的次数统计；
  • 主页访问记录：谁访问了你的个人主页（展示最近 20 位访客，互相可见）。

2.4 管理员提供的技术凭据

  • 下载机器人 Token（由管理员在后台添加，仅用于连接 Discord API 下载数据，不会展示给其他用户）。

2.5 自动收集的技术信息

  • 登录状态 Cookie（签名后的会话数据，仅含用户 ID、用户名、头像和服务器列表摘要，不包含密码或 Token）；
  • 服务器访问日志（IP 地址、请求路径、时间，用于安全审计与故障排查，日志自动轮转并定期覆盖）。

3. 我们如何使用数据

  • 生成词云、排行榜、互动关系、活跃趋势等统计分析并在看板展示；
  • 判断你对服务器数据的访问权限；
  • 驱动机器人的收藏、拉黑拦截、成员同步等功能；
  • 下载任务的状态跟踪与失败通知。

我们不做什么：不出售数据；不向广告商共享数据；不将数据用于本站说明之外的用途；不给用户发送营销信息。

4. 数据的存储与保护

  • 所有数据存储在运营者控制的 VPS 上的本地 SQLite 数据库中，不使用第三方云存储；
  • 站点通过 HTTPS 提供服务，登录凭据使用签名 Cookie；
  • 机器人 Token 与 OAuth Secret 仅保存在服务器端配置中，日志中自动脱敏；
  • 仅管理员和白名单授权用户可以访问对应服务器的数据。

5. 数据的共享

  • Discord：登录与数据下载必须与 Discord API 交互，受 Discord 隐私政策约束；
  • Cloudflare：站点通过 Cloudflare 提供 CDN 与防护，其会处理请求 IP 等技术信息；
  • 除上述服务外，不会向任何第三方提供你的数据（法律强制要求除外）。

6. 数据保留与删除

  • 消息分析数据在服务器持续运营期间保留；服务器数据被管理员删除时，对应分析库一并删除；
  • 你可以联系管理员（见第 8 节）要求删除你的个人数据（收藏、拉黑记录、主页访问记录、账户信息）；
  • 访问日志按轮转策略自动覆盖。

7. 你的选择

  • 不想被统计：请避免在已授权分析的公开频道发言，或联系管理员将服务器移出分析范围；
  • 拉黑某用户后，双方无法互相回复、@提及，机器人会自动删除相关消息并通知发送者；
  • 收藏与拉黑数据仅本人和管理员可见，其他用户无法查看你的列表。

8. 联系我们

对本政策或数据处理的任何问题、更正或删除请求，请在 Discord 服务器内联系管理员（Admin 权限成员），或通过本站后台的审核流程提交。

9. 政策更新

机器人新增收集内容或数据处理方式变化时，我们会更新本页面的「最近更新」日期并如实描述新增内容。继续使用本站即表示接受更新后的政策。

1. Who We Are

"抽象派档案馆" (the "Site") is a Discord community analytics dashboard operated by community administrators. It collects discussion data from public channels and Forum posts in authorized Discord servers via Discord bots, and presents it as statistical dashboards. This policy explains what we collect, how we use it, and how we protect it.

2. Data We Collect

2.1 Via Discord OAuth Login

  • Your Discord user ID, username, and avatar — to create and identify your account;
  • Your guild list and your permission level in each (owner / administrator) — to determine which server data you may view. Fetched once at login.

2.2 Via Data Download Bots (from authorized servers)

DataDetails
Message content & timestampsText and send time of messages in public channels and Forum posts
Message IDs & reply relationsUsed to reconstruct discussion threads
ReactionsWho reacted to which message with which emoji, for engagement statistics
MentionsWho mentioned whom, for interaction statistics
Attachment metadataFilename, URL and size (attachment contents are not downloaded)
Member rosterMember IDs, nicknames and avatars (synced on join/update)

2.3 Via Bot Interactive Features

  • Favorites: which post you favorited (user ID, guild ID, thread ID, timestamp);
  • Blocking: whom you blocked, when, and interception counts performed by the bot on your behalf;
  • Profile visits: who viewed your profile page (last 20 visitors are shown, mutually visible).

2.4 Technical Credentials Provided by Administrators

  • Download bot tokens (added by admins, used solely to call the Discord API for data download; never shown to other users).

2.5 Automatically Collected Technical Information

  • Session cookie (signed; contains only user ID, username, avatar and a summary of your guild list — no passwords or tokens);
  • Server access logs (IP address, request path, time — for security auditing and troubleshooting; rotated automatically).

3. How We Use Data

  • Generating word clouds, leaderboards, interaction graphs and activity trends on the dashboard;
  • Determining your access to server data;
  • Powering bot features: favorites, block interception, member sync;
  • Download task status tracking and failure notifications.

What we do NOT do: we do not sell data, share it with advertisers, use it beyond the purposes described here, or send marketing messages.

4. Storage & Protection

  • All data is stored in local SQLite databases on operator-controlled VPS servers — no third-party cloud storage;
  • The site is served over HTTPS; login state uses signed cookies;
  • Bot tokens and OAuth secrets are kept in server-side configuration only and are redacted from logs;
  • Only admins and whitelisted users may access the data of the corresponding servers.

5. Data Sharing

  • Discord: login and data download require interaction with the Discord API, governed by Discord's own privacy policy;
  • Cloudflare: the site is served through Cloudflare CDN, which processes technical data such as request IPs;
  • Beyond the above, your data is never shared with any third party (except where legally required).

6. Retention & Deletion

  • Analytics data is retained while the server remains in operation; when an admin deletes a server's data, its analytics database is removed with it;
  • You may contact an administrator (Section 8) to request deletion of your personal data (favorites, block records, profile visits, account info);
  • Access logs are overwritten automatically per rotation policy.

7. Your Choices

  • To avoid statistics: refrain from posting in public channels of analyzed servers, or ask an admin to remove the server from analysis;
  • After blocking a user, neither party can reply to or @mention the other; the bot deletes such messages automatically and notifies the sender;
  • Favorites and block records are visible only to you and administrators — other users cannot see your lists.

8. Contact

For any questions, corrections or deletion requests regarding this policy or data handling, contact an administrator (members with Admin permission) in the Discord server.

9. Policy Updates

Whenever the bot starts collecting new types of content or data handling changes, we will update the "Last updated" date on this page and describe the additions truthfully. Continued use of the Site constitutes acceptance of the updated policy.
